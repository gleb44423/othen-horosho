Как запустить

 1. Скачайте или клонируйте репозиторий:

git clone https://github.com/ВАШ-НИК/ВАШ-РЕПОЗИТОРИЙ.git

 2. Откройте index.html в любом современном браузере (Chrome, Firefox, Safari, Edge).

Установка и сборка не нужны.

Публикация на GitHub Pages

 1. Загрузите все файлы в репозиторий.
 2. Откройте Settings → Pages.
 3. В разделе Branch выберите main и папку / (root), нажмите Save.
 4. Через минуту сайт будет доступен по адресу https://ВАШ-НИК.github.io/ВАШ-РЕПОЗИТОРИЙ/.
Каждый сайт целиком находится в одном файле: разметка, стили и скрипт.
